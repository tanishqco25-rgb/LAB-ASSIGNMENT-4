# 🧠 Simple JavaScript Quiz Game

This is a basic, browser-based quiz game implemented using plain HTML, CSS, and JavaScript.

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites

You only need a modern web browser (like Chrome, Firefox, or Edge) to run this game.

### Installation and Setup

1.  **Clone or Download:** Download the `game.html` and `game.js` files to a local directory on your computer.
2.  **Run the Game:** Open the `game.html` file directly in your web browser.

    The quiz will load immediately, and you can start answering the questions.

## 🎮 How to Play

1.  Select one option for each question by clicking the corresponding button.
2.  Once you have made your selections, click the **"Submit Quiz"** button at the bottom.
3.  The results will be displayed, showing your final score and highlighting the correct (green) and incorrect (red) answers.

## ⚙️ Project Structure

* `game.html`: The main structure of the quiz, including the container where questions are rendered and basic styling.
* `game.js`: Contains the quiz logic, the array of questions, functions to render the quiz interface, capture user input, calculate the score, and display the results using the Document Object Model (DOM).

## 💻 Built With

* **HTML5:** For the main web page structure.
* **CSS3:** For basic styling to make the quiz presentable.
* **JavaScript (ES6+):** For the core quiz logic and DOM manipulation.
